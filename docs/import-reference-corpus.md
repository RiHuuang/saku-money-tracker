# Indonesian import reference corpus

Public provider research was checked 2026-10-16; OVO's terms were rechecked 2026-10-19. These guides are **not** customer statements or copied banking screenshots. They establish available surfaces and edge cases; actual column layouts and current app pixels still need private, consented checks. Keep public fixtures synthetic and do not commit real account numbers, names, balances, or transaction IDs.
